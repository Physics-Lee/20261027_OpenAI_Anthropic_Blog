## 本周概览

本周是监控启动以来对比最悬殊的一周：OpenAI 单方面输出 25 篇新文章，Anthropic 零发布（递交 S-1 后进入静默期，直至下周的 11-10 才以 IPO 路演公告打破）。OpenAI 本周的主线高度聚焦：**网络安全从"案例叙事"升级为"产品发布"**——周三发布网络安全专用模型 GPT-6 Cyber（ExploitGym 较上代提升 51%，配套 10 亿美元防御者补贴），同日披露自主管线修复 948 个 Linux 内核提权漏洞，Daybreak Red 进入 AWS GovCloud，叠加周一的漏洞赏金加码与安全冲刺，安全类内容约占全周三分之一。其余亮点包括收购 Pierre Computer（为 Codex 补齐 Git 工具链）、Images 2.6 发布、LifeVal/BioBasicsBench 两个新基准，以及 Jill Hazelbaker（首席企业事务官）与 Dan Driscoll（国家安全顾问）两笔高层人事。企业渠道与案例文持续高频，AWS、Cisco、Franklin Templeton 等大客户故事不断。

## 重点动态

- **GPT-6 Cyber 发布（11-05）**：OpenAI 首个网络安全专用模型，定位"发现漏洞并生成修复、恪守授权范围"的 aligned agent；实战发现 948 个 Linux 内核提权漏洞、81 个 Firefox 高危漏洞，ExploitGym 48.5%（较 GPT-5.6 Cyber 相对提升 51%），无提示下越界拒绝率 99.93%。10 月密集的 Daybreak 案例文至此收束为正式产品线，网络安全成为 GPT-6 时代第一个专用垂直模型。[原文](https://openai.com/index/introducing-gpt-6-cyber)
- **收购 Pierre Computer Company（11-04）**：旗下 Code Storage 与 Trees/Diffs/Highlights 开源工具将整合进 Codex，与 11-02 披露的自研 Git 后端 Pando（《Scaling Git at OpenAI》）形成"自建 + 收购"组合——OpenAI 在重造 agent 时代的版本控制底座。[原文](https://openai.com/index/openai-to-acquire-pierre)
- **《A thousand fewer paths to root》（11-04）**：全自动"发现-验证-补丁"管线处理 948 个 Linux 内核本地提权漏洞，是 GPT-6 Cyber 能力的直接实证，也是 OpenAI"AI 安全反哺开源生态"叙事的关键素材。[原文](https://openai.com/index/a-thousand-fewer-paths-to-root)
- **Daybreak Red 上线 AWS GovCloud（11-04）**：GPT-5.6 Cyber 经 Amazon Bedrock 进入美国政府云，配合上周 Anthropic 的 GSA 折扣，两家的政府安全市场正面交锋。[原文](https://openai.com/index/daybreak-red-aws-govcloud)
- **LifeVal 基准（11-02）**：基于时间使用研究与近 4,000 人调查，评测 AI 完成找房、照护、理财等日常任务的能力——"AI 有用性"的民间度量衡，与 BioBasicsBench（11-06，湿实验代理基准）构成 OpenAI 的评测体系扩张。[原文](https://openai.com/index/lifeval)
- **两笔高层人事（11-02 / 11-03）**：Dan Driscoll 出任国家安全现代化高级顾问；前科技大厂高管 Jill Hazelbaker 出任首席企业事务官，执掌全球传播与企业定位——政府关系与公关双线补强，为 OpenAI 自身的资本化周期做准备。[原文](https://openai.com/index/jill-hazelbaker-chief-corporate-affairs-officer)
- **Images 2.6（11-04）**：更快生成、GIF 创建、精准编辑与新 API 控制，覆盖 ChatGPT/Codex/API——多模态产品线的例行升级。[原文](https://openai.com/index/introducing-images-2-6)
- **算力扩张配套政策（11-02 / 11-05）**：Grid Protectors Program（电网守护者）与 National Community Compact、Compute Campus Policy Blueprint 先后发布，为超大规模算力园区预铺能源与社区接受度。[原文](https://openai.com/index/setting-new-standard-responsible-ai-infrastructure)
